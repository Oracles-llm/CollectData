# Strategy Design Pattern — All You Need To Know

## A behavioral design pattern that gives you control to make a decision dynamically

The Strategy design pattern is a behavioral design pattern that lets you define a family of algorithms, encapsulate each one within a different object, and make them interchangeable.

** It lets you vary the algorithm’s behavior without changing the context that uses it**. This pattern promotes loose coupling between the context and the strategy objects, making the code more extensible and maintainable.
